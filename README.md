# landing-page-consultoria-financeira
Modelo de Landing Page de alta conversão para consultoria, desenvolvido com HTML5, CSS3, JavaScript e Bootstrap 5.
🚀 Landing Page de Consultoria Financeira e Produtividade

Este projeto é um modelo de Landing Page (Página de Destino) de alta conversão, ideal para consultores, coaches e profissionais liberais que desejam capturar leads e agendamentos de forma eficaz.

Desenvolvido como um microserviço, ele demonstra a habilidade de criar interfaces rápidas, profissionais e totalmente responsivas utilizando apenas tecnologias Front-end essenciais.

🌟 Tecnologias Utilizadas

HTML5: Estrutura semântica do conteúdo.

CSS3: Estilização personalizada.

JavaScript: Validação de formulário simples e interação básica.

Bootstrap 5: Framework para garantir o design responsivo e acessível (Mobile-First).

✨ Principais Características

Design Responsivo: Layout adaptável a qualquer dispositivo (celular, tablet e desktop) usando o sistema de grid do Bootstrap.

Seção Hero de Alto Impacto: Chamada para Ação (CTA) clara e formulário de agendamento em destaque.

Formulário de Contato: Validação simples em JavaScript para garantir que campos essenciais sejam preenchidos.

Prova Social: Seção de depoimentos para aumentar a credibilidade.

Contato Direto: Link rápido para WhatsApp com mensagem pré-definida.
